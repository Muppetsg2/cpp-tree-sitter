# Benchmark results

Files in this directory are generated by the [`Benchmarks`](../../.github/workflows/benchmarks.yml) GitHub Actions
workflow (*Actions* → *Benchmarks* → *Run workflow*). Each run overwrites the file of every configuration it measured.

File name: `<system>-<compiler>-cxx<standard>.txt`

| Part         | Values                                                         |
|:-------------|:---------------------------------------------------------------|
| `<system>`   | `linux`, `macos`, `windows`                                    |
| `<compiler>` | `gcc`, `clang` (Linux), `appleclang` (macOS), `msvc` (Windows) |
| `<standard>` | `11`, `14`, `17`, `20`, `23` (MSVC has no C++11 mode)          |

Every file starts with the configuration, the runner image, the commit and the date of the run, followed by the
benchmark output (the compiler version is printed in the benchmark header). All builds use Release mode with IPO and
include the Wasm benchmarks.

GitHub-hosted runners are shared virtual machines: compare the wrapper/C API overhead inside one file rather than
absolute times between files. See [`BENCHMARK.md`](../BENCHMARK.md) for the methodology.
